Maat API Reference - Complete Browser Automation API in Zig

Maat is a Playwright-like browser automation framework written in Zig with sandbox enabled by default.

Supported browsers: Chromium (CDP), Firefox (WebDriver BiDi), WebKit/Safari (WebDriver).

Security: Sandbox ON by default. Addresses CVEs CVE-2026-118306, CVE-2026-118331, CVE-2026-118348, CVE-2026-118344.

Browser

Classe principal para lançamento e gerenciamento de navegadores.

pub const Browser = struct {
  allocator: std.mem.Allocator,
  name: BrowserName,
  cdp_client: CdpClient,
  debug_port: u16,
  process: ?std.process.Child,
  
  pub fn launch(allocator, opts: LaunchOptions) !Browser,
  pub fn newPage(self: *Browser) !Page,
  pub fn newContext(self: *Browser) !BrowserContext,
  pub fn close(self: *Browser) void
};
launch() static method
Lança uma instância do navegador com sandbox ativado por padrão. Retorna uma instância de Browser.
newPage() instance method
Cria uma nova página/aba no navegador.
newContext() instance method
Cria um contexto de navegação isolado (cookies, localStorage, sessionStorage isolados).
close() instance method
Fecha o navegador e encerra o processo.
Exemplo: Launch com sandbox ativo
const browser = try maat.Browser.launch(allocator, .{
    .name = maat.BrowserName.chromium,
    .headless = false,
    .security = .{ .sandbox = true }, // sandbox ON by default
  });
defer browser.close();

Page

Classe para operações de página: navegação, cliques, preenchimento, screenshots, título.

  pub fn fill(self: *Page, selector: []const u8, value: []const u8) !void,
  pub fn press(self: *Page, key: []const u8) !void,
  pub fn title(self: *Page) ![]u8,
  pub fn screenshot(self: *Page, path: []const u8) !void,
  pub fn evaluate(self: *Page, expression: []const u8) ![]u8,
  pub fn waitForSelector(self: *Page, selector: []const u8, timeout_ms: u64) !void,
  pub fn close(self: *Page) void

click()Clica em um elementoselector
fill()Preenche um campo de formulárioselector, value
press()Pressiona uma teclakey

Nota para Agentes de IA

Todos os métodos de Page enviam comandos CDP (Chrome DevTools Protocol) internamente. O método goto() aceita WaitUntil.load, WaitUntil.domcontentloaded ou WaitUntil.networkidle.

Exemplo: Navegação completa
var page = try browser.newPage();
defer page.close();

try page.goto("https://example.com", maat.WaitUntil.load);
try page.click("button.submit");
try page.fill("input#username", "testuser");
try page.press("Enter");
const title = try page.title();
try page.screenshot("resultado.png");
const js_result = try page.evaluate("document.title");

BrowserContext

Contexto de navegação isolado (cookies, localStorage, sessionStorage isolados por contexto).

pub const BrowserContext = struct {
  allocator: std.mem.Allocator,
  name: BrowserName,
  cdp_client: CdpClient,
  context_id: []const u8,
  
  pub fn newPage(self: *BrowserContext) !Page,
  pub fn cookies(self: *BrowserContext) ![]u8,
  pub fn setCookie(self: *BrowserContext, name: []const u8, value: []const u8) !void,
  pub fn close(self: *BrowserContext) void
};
newPage() instance method
Cria uma nova página dentro deste contexto isolado.
cookies() instance method
Obtém todos os cookies deste contexto.
setCookie() instance method
Define um cookie neste contexto.
Exemplo: Contexto isolado com cookies
var ctx = try browser.newContext();
defer ctx.close();

var page = try ctx.newPage();
try page.goto("https://example.com", maat.WaitUntil.load);

// Definir cookie
try ctx.setCookie("session_id", "abc123");

// Obter cookies
const cookies = try ctx.cookies();

CdpClient (Chrome DevTools Protocol)

Cliente de baixo nível para comunicação com o Chrome DevTools Protocol sobre WebSocket.

pub const CdpClient = struct {
  pub fn connect(allocator, host, port, path) !CdpClient,
  pub fn send(self: *CdpClient, method, params) !u64,
  pub fn call(self: *CdpClient, method, params, timeout_ms) ![]const u8,
  pub fn close(self: *CdpClient) void,
  pub const Frame = struct { fin, opcode, masked, payload },
  pub fn buildFrame(payload, allocator) ![]u8
};
connect() static method
Conecta via WebSocket ao navegador (handshake HTTP Upgrade).
send() instance method
Envia um comando CDP e retorna o request id.
call() instance method
Envia um comando CDP e aguarda a resposta com timeout.
buildFrame() static method
Constrói um frame WebSocket com máscara cliente→servidor (pronto para envio via TCP).

ContextStore (Agent Communication Graph)

Loja de contexto compartilhada para comunicação entre agentes sem desperdiçar contexto de janela.

pub const ContextStore = struct {
  pub fn init(allocator) !ContextStore,
  pub fn publish(allocator, topic, data) !u64,
  pub fn subscribe(allocator, topic) !ContextSnapshot,
  pub fn isStale(topic, since_version) bool,
  pub fn deinit(self: *ContextStore) void
};

pub const ContextSnapshot = struct {
  topic: []const u8,
  data: []const u8,
  version: u64,
  global_version: u64
  pub fn deinit(self: *ContextSnapshot, allocator) void
};
Exemplo: Comunicação entre agentes
var store = try maat.ContextStore.init(allocator);
defer store.deinit();

// Agente A publica status
const v = try store.publish(allocator, "agent-a/status", "working");

// Agente B lê o status
var snap = try store.subscribe(allocator, "agent-a/status");
std.debug.print("Status: {s}\n", .{snap.data});
snap.deinit(allocator);

Segurança

SANDBOX ON BY DEFAULT

Maat executa navegadores com sandbox ativado por padrão. Isto difere do Playwright, que frequentemente roda com --no-sandbox em ambientes CI.

.security = .{ .sandbox = true } padrão
Mantém o sandbox ativo do navegador.
.security = .{ .sandbox = false } opt-in
Desativa o sandbox (apenas em ambientes isolados e confiáveis). NÃO recomendado para produção.

CVEs abordadas: CVE-2026-118306, CVE-2026-118331, CVE-2026-118348, CVE-2026-118344. Reimplementar a orquestração em Zig reduz a superfície de ataque escrita em linguagens inseguras.
