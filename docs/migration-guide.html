De Playwright para Maat — Automação de navegador em Zig com sandbox ativo por padrão

Home > Guia de Migração

Por que migrar para o Maat?

  • Sandbox ativo por padrão — Diferente do Playwright que frequentemente roda com --no-sandbox em CI
  • Segurança de memória — Escrito em Zig, sem classes inteiras de vulnerabilidades (use-after-free, buffer overflow)
  • Multi-navegador — Chromium (CDP), Firefox (WebDriver BiDi), WebKit/Safari (WebDriver)
  • API similar ao Playwright — Curva de aprendizado mínima
  • Endereça CVEs — CVE-2026-118306, CVE-2026-118331, CVE-2026-118348, CVE-2026-118344

Exemplo de Migração: Navegação Básica

Playwright (TypeScript)
import { test, expect } from '@playwright/test';

test('example page', async ({ page }) => {
    await page.goto('https://example.com');
    await page.click('button.submit');
    await page.fill('input#username', 'testuser');
    const title = await page.title();
    console.log('Título:', title);
    await page.screenshot({ path: 'resultado.png' });
});
Maat (Zig)
const std = @import("std");
const maat = @import("maat");

pub fn main() !void {
  var gpa = std.heap.GeneralPurposeAllocator(.{}){};
  const allocator = gpa.allocator();

  var browser = try maat.Browser.launch(allocator, .{
    .name = maat.BrowserName.chromium,
    .headless = false,
 &   .security = .{ .sandbox = true },
  });
  defer browser.close();

  var page = try browser.newPage();
  defer page.close();

  try page.goto("https://example.com", maat.WaitUntil.load);
  try page.click("button.submit");
  try page.fill("input#username", "testuser");
  const title = try page.title();
  std.debug.print("Título: {s}\n", .{title});
  try page.screenshot("resultado.png");
}

Passos para Migrar

  1. Instale o Zig — Versão 0.17.0 ou superior
  2. Clone o repositório — git clone https://github.com/developerfred/maat.git
  3. Build — zig build
  4. Reescreva seus testes — Substitua chamadas do Playwright por equivalente em Maat
  5. Configure sandbox — Mantenha .sandbox = true por padrão
  6. Execute testes — zig build test
Aviso Importante

O Maat está em desenvolvimento ativo. Algumas funcionalidades avançadas do Playwright (codegen, trace viewer, codegen CLI) ainda não estão implementadas. Consulte o ISSUES_PLANEJADAS.md para o roadmap completo.
